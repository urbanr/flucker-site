Flucker Support

Flucker is a dual-panel file manager for macOS.

Get Flucker on the Mac App Store

Start with the Help. It shows the main features in 20 short chapters.

Report a problem or ask a question

Write to flucker@urbn.team, or open an issue at github.com/urbanr/flucker-site/issues. A GitHub account is needed. Please include the version of Flucker (Flucker › About Flucker) and of macOS.

Do not post the names of your files or folders if they are private. When asked for diagnostics, hold ⌥ and choose Help › Export Diagnostics…: the exported file is shown to you whole before it is saved and contains no names of files, folders or volumes and no paths.

Useful to know

  • The window Welcome to Flucker (Window menu) sets the full-text engine, appearance, places and favourites.
  • All keyboard shortcuts: Window › Keyboard Shortcuts Overview (⌘').
  • The App Store edition opens only the folders you allow it to. Window › Granted Access lists them.

Podpora (česky)

Napište na flucker@urbn.team, nebo problém či dotaz založte jako issue na github.com/urbanr/flucker-site/issues (potřebujete účet GitHub). Uveďte verzi Fluckeru (Flucker › O aplikaci Flucker) a macOS. Soukromá jména souborů a složek nezveřejňujte. Diagnostiku exportujte přes Nápověda › Exportovat diagnostiku… se stisknutou klávesou ⌥. Soubor neobsahuje jména souborů, složek, svazků ani cesty.
